# Abdel's personal site
[![Open in DevPod!](https://devpod.sh/assets/open-in-devpod.svg)](https://devpod.sh/open#https://gitlab.com/abogical/abogical)

Made with [Lume](https://lume.land) and [PostCSS](https://postcss.org/)

## Try it yourself

1. This repository currently uses DevPod which sets up the development enviroment with all the dependencies under an isolated container. Guide to install and use Devpod are detailed here: https://devpod.sh/docs/getting-started/install
2. Create a workspace with this source git repo. You can do this with the DevPod GUI or with the CLI:
```
devpod up https://gitlab.com/abogical/abogical
```
3. After the IDE is open, start a server by running `deno task serve` in the terminal.
